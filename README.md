# Java-Script-projects
# 🚀 JavaScript Logic Basics Exercises (Pure JS)

A collection of 7 simple, standalone functions written in modern JavaScript (ES6+). These exercises are designed to strengthen core programming logic without relying on any HTML/DOM interfaces.

---

## 💡 Included Exercises

### 1. Number Analyzer
* **Function:** `analyzeNumber(num)`
* **Description:** Takes a number and returns a string describing it (e.g., "Positive", "Negative", or "Zero").

### 2. Random Picker
* **Function:** `pickRandomItem(list)`
* **Description:** Takes an array and returns one random item from it.

### 3. Grade Filter
* **Function:** `getPassingGrades(gradesList)`
* **Description:** Takes an array of numbers (grades) and returns a new array containing only the passing grades (60 or higher).

### 4. Vowel Counter
* **Function:** `countVowels(text)`
* **Description:** Takes a string and returns a "number" representing the count of vowels (a, e, i, o, u) within it.

### 5. Find Max Number
* **Function:** `findMax(numbers)`
* **Description:** Takes an array of numbers and returns the "largest number" found in that array.

### 6. Filter Student Objects
* **Function:** `getNamesByMajor(studentsList, major)`
* **Description:** Takes an array of student "objects" and a "major" name. It returns a new array containing only the names of students matching that major.

### 7. String Reverser
* **Function:** `reverseString(text)`
* **Description:** Takes a string and returns a "new string" that is reversed (e.g., "Hello" becomes "olleH").

---

## 🔧 How to Use

These functions are ready to run in any JavaScript environment.
1.  Copy the function you want.
2.  Paste it into your browser's Console or your `.js` file.
3.  Call it with the required data.
